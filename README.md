# Análisis exploratorio de las horas extraordinarias en España

## Descripción

Proyecto de análisis exploratorio de datos (EDA) realizado a partir de información de la Encuesta de Población Activa (EPA) del Instituto Nacional de Estadística (INE).

El objetivo del proyecto es estudiar la evolución de las horas extraordinarias en España, comparar las horas remuneradas y no remuneradas e identificar los sectores económicos con mayor volumen de horas extra.

## Preguntas de investigación

- ¿Cómo ha evolucionado el número de trabajadores que realizan horas extraordinarias?
- ¿Qué peso tienen las horas extraordinarias no remuneradas?
- ¿Existen diferencias entre sectores económicos?

## Principales hallazgos

- Se observa una fuerte caída de las horas extraordinarias tras la crisis económica de 2008, seguida de una recuperación progresiva.
- Las horas extraordinarias no remuneradas mantienen una presencia significativa durante todo el periodo analizado.
- Educación, Transporte e Industria manufacturera concentran los mayores volúmenes de horas extraordinarias no pagadas.
